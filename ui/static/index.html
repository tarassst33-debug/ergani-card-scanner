      Ψηφιακή κάρτα εργασίας

      Σήμερα: προσωπικό με ώρες · Check-in/out ανά άτομο. Εβδομάδα: πίνακας — κλικ σε κελί για ώρες Πρ./Απ. · υποβολή μαζική από Πρ. / Απ. στην ημέρα.

      Σήμερα — προσωπικό & ώρες Ergani

      Οι ώρες έρχονται από το κελί της σημερινής ημέρας στον πίνακα (ή από το + κάτω δεξιά).

      Φόρτωση προσωπικού…

      Πρόγραμμα εβδομάδας

      Κενά κελιά — κλικ για μικρό πίνακα ώρων (Πρ./Απ. ή ΡΕΠΟ). Επικόλληση: ΑΦΜ, Όνομα, Επώνυμο.

      Φόρτωσε προσωπικό ή πρόσθεσε εργαζόμενους για να εμφανιστεί ο πίνακας.

      24ωρη μορφή · π.χ. 09:00, 13:00 (χωρίς πμ/μμ)

      Για ώρες στο παρελθόν μπορεί να απαιτείται αιτιολογία εκπρόθεσμου.

      Προσωπικό — Check-in / Check-out

      Επίλεξε άτομα και ώρα αποστολής στο Ergani.

      Υπερωρίες

      Υποβολή δήλωσης υπερωριών (OvTime).

      Ημερήσιο πρόγραμμα

      Για εργαζόμενους χωρίς σταθερό ωράριο (WTODaily).

      Εβδομαδιαίο πρόγραμμα

      Για σταθερό ωράριο — μία ημέρα ανά υποβολή (WTOWeek).

      Λίστα υπηρεσιών API
